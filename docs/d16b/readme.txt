# CII

D16B_SCRDM__Subset__CII_coupled.zip / D16B_SCRDM__Subset__CII_uncoupled.zip
  The original download "D16B SCRDM (Subset) CII.zip" contained both variants; it was
  split into one ZIP per variant. This project uses the uncoupled one.

D16B SCRDM (Subset) CII uncoupled.zip
  The uncoupled variant alone - identical to the inner ZIP of
  D16B_SCRDM__Subset__CII_uncoupled.zip.

d16b-xsds-scrdm-uncoupled.zip
  Only the 4 "data/standard" XSDs of the uncoupled variant.

D16B.zip
  The complete UN/CEFACT D16B schema library, not a CII specific coupled/uncoupled
  publication.
