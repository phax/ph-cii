# CII

Source page: https://unece.org/trade/uncefact/xml-schemas

SCRDM_CCBDA_CII_D16A.1_30MAY2016_coupled.zip
  The only D16A.1 publication available - it is a "coupled" one, meaning that the
  qdt:QualifiedDataType schema module imports all code list and identifier scheme schemas.
  UN/CEFACT did not publish an "uncoupled" variant for D16A.1, so - unlike all the other
  CII versions in this project - D16A.1 is used in its coupled form.
